# Шпаргалка биндов Hyprland

**Mod = Super (Win)**

## Основное
| Бинд | Действие |
|---|---|
| `Super+Enter` | Терминал (kitty) |
| `Super+D` | Лаунчер приложений (wofi) |
| `Super+Q` | Закрыть окно |
| `Super+E` | Файловый менеджер (Thunar) |
| `Super+V` | Плавающее окно (toggle) |
| `Super+F` | Полный экран |
| `Super+P` | Псевдоплитка |
| `Super+J` | Переключить сплит |
| `Super+H` | Эта шпаргалка |

## Раскладка
- `Alt+Shift` (в любом порядке) — RU/EN

## Окна
| Бинд | Действие |
|---|---|
| `Super+стрелки` | Фокус между окнами |
| `Super+Shift+стрелки` | Перенести окно |
| `Super+ЛКМ` | Перетаскивать окно |
| `Super+ПКМ` | Менять размер окна |

## Рабочие столы (5)
| Бинд | Действие |
|---|---|
| `Super+1..5` | Перейти на стол |
| `Super+Shift+1..5` | Окно на стол |
| `Super+Ctrl+стрелки` | След/пред стол |
| `Super+колесо` | Листать столы |

## Scratchpad
- `Super+S` — показать/спрятать стол «magic»
- `Super+Shift+S` — закинуть окно туда

## Звук / система
| Бинд | Действие |
|---|---|
| `Super+Alt+↑/↓` | Громкость |
| `Super+Alt+Space` | Мьют |
| `XF86 клавиши` | Громкость/мьют |
| `Super+L` | Погасить экран |
| `Super+Shift+R` | Перезагрузить конфиг |
| `Super+Shift+C` | Выход из Hyprland |

## Скриншоты
- `Print` — область в буфер обмена
- `Super+Print` — весь экран в ~/Pictures
